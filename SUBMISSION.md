# How to submit

**Deadline: 16:00.** One submission per team.

## What you need

1. **A public GitHub repo** with your code, an open source licence, and a README based on [templates/PROJECT_README.md](templates/PROJECT_README.md).
2. **The required README section: "Where Claude works".** What Claude does every time someone uses your solution: the model, the prompts, the tools or MCP servers it calls, what it decides and what a human confirms. Without this section, "AI at work" scores 0.
3. **A two-minute demo video** (optional, strongly recommended). A screen recording is enough. Upload it anywhere with a public link (YouTube unlisted, Loom, Google Drive). It makes judging much easier and saves your pitch if the live demo fails.

## How to submit

Open a new issue in this repo with the **Submission** form:

👉 **[Submit your project](../../issues/new?template=submission.yml)**

You can edit your issue until 16:00. After that, the staff locks submissions.

## Checklist before 16:00

- [ ] The repo is public
- [ ] README complete, track named
- [ ] "Where Claude works" section written
- [ ] Two-minute demo recorded
- [ ] No personal data anywhere: code, data files, screenshots, video
- [ ] No API keys in the repo (check `.env` is in `.gitignore`)
- [ ] Submitted once, with the form

## The pitch: two minutes, four beats

| Time | Beat |
|---|---|
| 20″ | **The problem**: who gets stuck, and where |
| 60″ | **The demo**: live or recorded, working |
| 20″ | **Where Claude works**: what AI does at runtime |
| 20″ | **Day one**: what the City needs to switch it on |
